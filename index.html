플레이 도움말

“주변을 둘러본다”, “차장을 찾아간다”, “자정의 행적을 묻는다”, “서류를 조사한다”, “질문을 정리한다”처럼 말해보세요.

판정은 기본 1d6, 준비·전문성에 각각 +1d입니다. 강경함은 기준 미만, 공감은 기준 초과일 때 성공합니다. 기준과 같으면 실패입니다.

성공 0: 단서 없음. 1: 단서 하나와 시간 비용. 2: 단서 하나. 3: 단서 둘과 다음 판정 준비 보너스.

개인 목표는 역할극용 메모입니다. 이 데모의 승패는 공동 수사 목표로 결정합니다.

마스터 연결

OpenAI API 키를 입력하면 자연어를 해석하고 NPC 대화를 이어갑니다. 키 없이도 기본 GM으로 플레이할 수 있습니다.

OpenAI API 키는 api.openai.com/v1로 전송됩니다. gpt-6-luna를 기본 모델로 사용합니다.

OpenAI API 키는 OpenAI Platform에서 발급할 수 있습니다. API 사용료는 ChatGPT 구독과 별도입니다. 키는 파일이나 브라우저 저장소에 저장하지 않습니다.

플레이는 자동 저장됩니다. 같은 브라우저·주소로 다시 열면 이어집니다.
