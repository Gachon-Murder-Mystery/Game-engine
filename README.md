# 오네이트 익스프레스 · 대화형 TRPG GM (v2)

마스터에게 자연어로 행동과 대사를 입력하는 로컬 데모입니다. 기존 버튼 중심 데모를 채팅, 장소 상태, NPC 기억, 판정 요청 흐름으로 리팩토링했습니다.

## 실행

Python **3.10 이상**이면 별도 패키지 설치가 필요 없습니다. 압축을 풀고 폴더 안에서 실행하세요.

```bash
python app.py
```

Windows에서는 `py app.py`도 가능합니다. 브라우저가 열리지 않으면 **http://127.0.0.1:8765/** 로 접속하세요. 종료는 터미널에서 Ctrl+C입니다.

## 플레이

1. **새 여행**에서 이름, 직업, 강경함 기준(2~5), 개인 목표를 정합니다.
2. **GM 연결**에서 OpenAI API를 선택하고 API 키와 모델을 설정합니다. 기본 모델은 `gpt-6-luna`이며, 키 없이도 기본 GM으로 진행할 수 있습니다.
3. 채팅창에 행동이나 대사를 입력합니다. Enter는 전송, Shift+Enter는 줄바꿈입니다.
4. 마스터가 판정을 요청하면 접근 방식을 확인하고 **주사위 굴리기**를 누르거나 “굴린다”라고 말합니다. 취소하거나 공감/강경함을 바꿀 수도 있습니다.
5. 단서 수첩에서 범인·흉기·장소 후보를 좁혀 최종 지목합니다. 첫 오답 후 한 번 더 기회가 있으며 두 번째 오답은 미제로 끝납니다.

예시:

- “주변을 둘러본다.”
- “차장을 찾아가 자정 무렵 어디에 있었는지 묻는다.”
- “차장의 긴장을 풀어주면서 알리바이를 확인한다.”
- “지금까지의 내용을 정리하고 다음 질문을 준비한다.”
- “금고 칸으로 이동한다.”
- “이곳의 장부를 조사한다.”
- “범인은 퀸 슬레이트, 흉기는 만년필, 장소는 금고 칸.”

준비하면 다음 판정에 +1d를 받습니다. 전문성은 직업과 행동에 따라 코드가 판단합니다. 기본 1d6, 준비·전문성에 각각 +1d이고, 기준과 같은 값은 실패입니다. 강경함은 기준 미만, 공감은 기준 초과가 성공입니다. 성공 1개는 단서 하나와 추가 시간 비용, 2개는 단서 하나, 3개는 단서 둘과 다음 판정 준비 보너스입니다. 남은 단서가 적으면 얻는 개수도 줄어듭니다.

## API 연결

기본 제공자는 OpenAI API입니다. OpenAI API 키는 `https://api.openai.com/v1/`에 Bearer 인증으로 전송합니다. 기본 모델은 `gpt-6-luna`, 기본 프로토콜은 Responses API입니다. API 사용료는 ChatGPT 구독과 별도이며 OpenAI Platform의 결제 설정을 따릅니다.

선택 목록에서 OpenCode Console 또는 OpenCode Zen으로 전환할 수도 있습니다. `oc_sk_` 서비스 키는 Console 경로에, Zen 키는 Zen 경로에 사용하세요.

공식 문서:

- OpenAI API 키: https://platform.openai.com/api-keys
- OpenAI Responses API: https://platform.openai.com/docs/api-reference/responses
- OpenCode Console 추론: https://opencode.ai/v2/docs/console/inference/
- OpenCode Console 모델/주소: https://opencode.ai/v2/docs/console/models/
- OpenCode Zen: https://opencode.ai/docs/zen/

401은 키 인증, 402는 결제/크레딧, 403은 키 권한·모델 접근, 404는 모델 ID/API 종류, 429는 요청 한도를 우선 확인하세요. 응답 코드와 제공자 설명을 화면에 표시하고 키 문자열은 가립니다. 연결 오류 때는 기본 GM으로 이어갑니다.
## 기억과 저장

현재 위치, 대화 상대, 준비 상태, 기다리는 판정, 단서와 출처, NPC별 대화 기록을 유지합니다. 사건은 `data/games.sqlite3`에 자동 저장되고, 브라우저는 마지막 사건의 식별자를 기억합니다. 같은 브라우저와 같은 주소에서 다시 열면 이어집니다. 포트나 브라우저를 바꾸면 이전 식별자가 자동으로 연결되지 않습니다. API 키는 다시 입력하세요.

**기록 저장**은 공개 대화·단서만 JSON으로 내려받습니다. 서버 데이터에는 사건의 정답도 있으므로, 공개 시에는 기록 저장 기능으로 생성한 파일을 사용하세요. 이 배포 ZIP에는 플레이 데이터와 키가 없습니다.

## 구현 구조

- `engine.py`: 사건 생성, 위치/NPC 접근, 준비·전문성, 판정, 단서와 최종 지목
- `llm.py`: OpenAI / OpenCode 어댑터, 구조화된 행동 해석, 공개 상태를 바탕으로 한 장면/NPC 서술
- `app.py`: 로컬 HTTP 서버, 요청 검증, 사건별 처리 잠금, SQLite 저장
- `index.html`: 채팅, 주사위 카드, 지도, 승객 명부, 수사 수첩
- `test_game.py`: 핵심 규칙·노출 범위·저장·API 어댑터 테스트

LLM은 제한된 행동을 제안하고 코드는 실행 가능 여부와 결과를 결정합니다. 비공개 정답과 미발견 단서는 LLM 요청과 플레이어 응답에 포함하지 않습니다. 단서마다 생성 시 고정한 조사 장소가 있으며, 해당 장소의 NPC도 그 자료를 제공할 수 있습니다. 반복 조사로 단서를 중복 획득하지 않습니다. LLM 서술과 별도로 **판정·확정 결과** 및 **확인된 단서** 카드를 보여줍니다.

## 데모 범위

1인 플레이용입니다. NPC는 고정된 칸에 머무르고, 단서의 근거는 간단한 자료 대조 문장으로 생성됩니다. 복잡한 증언 충돌, NPC 이동 일정, 다중 플레이어, 비밀 채널, PC 범인의 별도 정보 전달, 인벤토리/전투 규칙은 포함하지 않습니다. 개인 목표는 역할극용 메모이며 승패는 살인사건 해결로 판단합니다. 수사 경과는 행동 비용을 나타내는 값이고, 제한 시간으로 게임을 종료하지 않습니다.

키 없이 쓰는 기본 GM은 정해진 한국어 표현을 인식합니다. 자유로운 대화와 NPC 말투의 연속성은 OpenAI API 또는 OpenCode API에 연결하면 더 자연스럽습니다. 모델이 생성하는 서술은 완전히 검증할 수 없으므로, 확정된 사실은 수사 수첩과 결과 카드를 기준으로 판단합니다.
